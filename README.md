# DomoHub (web)

Control remoto de DomoHub para el iPhone (o cualquier navegador). Se agrega a la pantalla de inicio como una app.

- No contiene ninguna clave ni dato de la casa. La clave de vinculación queda guardada solo en el teléfono, al escanear el QR de la central.
- Se comunica con la central (NVIDIA Shield) por ntfy.sh, con mensajes cifrados de punta a punta (AES-256-GCM).
